## Backend (Code.gs)
- `Classes` sheet (id, name, period, admins, emails JSON, updated by/at); admin `listClasses`, `saveClass`, `deleteClass`.
- `Bank` sheet shared by all admins (id, question JSON, tags, added by/at, edited by/at); `listBank`, `saveBankItem`, `deleteBankItem`.
- Test JSON `classes: [classId]` and `rosterOnly: true`: `getTest` / `submit` refuse a verified student not on any
  assigned class (`not_on_roster`) server-side. Submissions columns `Drawn Questions`, `Class` filled on submit.
- Log every write. ARCHITECTURE.md contracts.
## Client
- `js/lib/pools.js`: `addInstantiateStep('pools', fn)`: a section with `pool: { draw: N, from: 'section'|{ tags: [...] } }`
  draws N questions per student with `rand`; `test.instance.drawn = [ids]`; payload carries drawn ids (results/grading/
  feedback/PDF already work from the submitted questions — verify and fix in owned files).
- Admin views: **Classes** (create by pasting emails or CSV import — Google Classroom / Aeries export columns; edit;
  assign tests), **Question bank** (search, tag filters topic/unit/difficulty/NGSS, preview, insert copy into the builder
  test, save any builder question to the bank, import all questions from a test, edit/delete with who/when),
  **Import** (plain-text numbered format, CSV, Google Forms export → draft test to review; pure parsers in
  `js/lib/importers.js` unit-tested), **Templates** (starter tests per unit in `data/templates/*.json`: atomic structure,
  bonding, stoichiometry, gases, solutions, acids/bases — valid tests, ~8 questions each).
- Builder: class assignment + Roster only in test settings; pool settings per section; "Save to bank" per question; "Insert from bank".
- Grading / Insights filter by class (Insights is `js/views/admin/insights.js` — not owned: report the hook).
- Nav: add Question bank + Classes entries to the admin nav list.
Tests: unit (parsers, pools draw determinism, roster check helpers, Code.gs via the apps-script test harness incl. roster-only refusal), E2E `test/e2e/v4-classes-bank.test.mjs`.
