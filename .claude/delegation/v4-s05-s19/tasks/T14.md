## Types (registry modules; group/shortLabel per plan; all keyboard-operable)
- `molarmass` (answer + optional work steps; built-in molar-mass checker shows the formula's molar mass to the teacher; auto on final answer within tolerance; work shown in review).
- `imagechoice` (single/multi like mcq/multi with image options; reuse option-image helpers; alt text required).
- `particles` (box with species palette; place/remove particles by click/keyboard; per-species & phase counts graded; review draws the box).
- `titration` (simple simulated curve from strong/weak acid-base parameters; "Add 1.00 / 0.10 mL" buttons + slider; student records endpoint volume / pH; auto within tolerance).
- `estimate` (slider with min/max/step + numeric readout; auto within tolerance).
Each: definition + UI + unit tests + entries in `data/tests/DEMOV4C.json` + E2E `test/e2e/v4-qtypes-s10.test.mjs` (with `FEATURES: { v4Types: true }`).

## Algorithmic (V4-09)
- `js/lib/chemfuncs.js`: `molarMass(formula)` (reuse `js/lib/elements.js` + formula parser), `moles`, unit conversion, ideal gas, dilution, pH — pure, unit-tested.
- `js/lib/algorithmic.js`: question field `variables: { m: { min, max, step, sigFigs }, compound: { pick: ['NaCl','KCl'] } }`;
  `{name}` placeholders in text/options/units; answer formula `answerFormula: "= m / molarMass(compound)"` evaluated with a
  tiny safe expression parser (numbers, + − × ÷ ^, parentheses, variables, whitelisted chemfuncs — **no eval / Function**).

  submitted question text/answers). Works for `numeric`, `sigfigs`, `dimensional`, `multipart`.
