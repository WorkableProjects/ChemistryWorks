## Build (behind `feature('adminShell')`; with the flag off the current tabs stay exactly as today, so existing E2E keeps passing)
1. **Shell** (`shell.js`, `css/admin-shell.css`): Classroom-style top bar (☰ toggle, ChemWorks mark, breadcrumb, profile
   picture top-right from `getUser()` / initials fallback → menu with name, email, theme toggle, sign out/lock), left
   sidebar (`nav` landmark, groups "Teaching": Dashboard, Library, Builder, Grading; "Tools": Insights, Question bank,
   Classes (hide entries whose views don't exist yet — Bank/Classes arrive in S11; read a `NAV_ITEMS` list that S11/S13 can
   extend), Settings at bottom; active item = rounded accent pill + `aria-current="page"`; optional Recent tests group),
   in-test horizontal tabs (Overview, Questions, Submissions, Insights, Settings — map to existing views), responsive:
   full ≥ 1200, icons-only 768–1199, drawer < 768; collapsed state per device (`load/save('adminNav')`). Every existing
   admin `data-testid` (e.g. `tab-library`, `tab-grading`, `lock-admin`, `sheet-link`) must still exist and work when the flag is on.
2. **Dashboard** (`dashboard.js`, first screen after sign-in when the flag is on): greeting from `js/lib/greetings.js`
   (≥ 10 per time slot from the plan list + day-of-week + Mole Day Oct 23; `{FirstName}` from the Google user or omitted;
   pure `pickGreeting(date, firstName, rand)` unit-tested), Needs attention (to grade per test, unreleased grades, flagged
   questions when present, version banner), Today/this week (open/close soon — read `test.opensAt/closesAt` if present),
   Recent activity (admin `getLog` if available, else hidden), Quick stats (published, submissions this week, latest class
   average → link to Insights), Quick actions (new test, open last edited, grade next, release all). One combined load:
   reuse the library + results fetches already used by those views; cards hide when their data is missing.
3. **Library**: card grid ⇄ table toggle (remembered), search, filters (published, has submissions, needs grading),
   quick actions per test (keep existing testids/buttons).
4. **Builder two-pane**: outline left (sections + questions, drag-and-drop with FLIP animation and keyboard reorder),
   editor right, "Preview as student" toggle (live preview using the runner widgets read-only, plus a fake-email box that
   runs `instantiateTest(test, { email })` so randomized numbers can be checked). Mount `gameOptionsPanel(test, changed)`
   from `js/views/admin/game-options.js` in the test settings when it returns a Node. Type picker: add icons + one-line
   hover description (FIX-2 picker stays).
5. **Grading split view**: student list | submission, J/K next/previous, number keys for points, sticky score bar,
   "Saved ✓" pop; list → submission slide on phones. Keep the S07 bulk tools, comment bank, Grade by question.
6. Motion per plan (sidebar slide, pill glide, tab underline slide, stagger cards ≤ 40 ms, count-up stats, popovers scale
   from anchor) using tokens; all off under reduced motion.
