## Types (all auto-graded, all keyboard-operable, no drag-only interaction)
- **dimensional** (Chemistry, "Dimensional analysis"): `{ given: { value, unit }, answer: { value, unit }, tolerance,
  toleranceType: 'absolute'|'percent', factors?: [{ top: {value, unit}, bottom: {value, unit} }] (teacher's reference
  chain), chainCredit: 0..1 (default 0) }`. Widget: the given quantity, then a row of fraction tiles the student adds
  ("Add factor" → numerator value+unit / denominator value+unit inputs), units that cancel are shown struck through
  (compute cancellation by unit tokens, e.g. "g", "mol", "g/mol" split on '/', '·', '*', spaces, exponents like "L^-1"
  optional — keep it simple and documented), then the final answer value + unit. Answer `{ factors: [...], value, unit }`.
  Score: final value within tolerance AND unit matches (case-sensitive for symbols, trimmed) → full; with
  `chainCredit > 0`, a chain whose units cancel to the answer unit and whose numeric product matches within tolerance earns
  that fraction even if the final entry is wrong.
- **nuclear** (Chemistry, "Nuclear notation"): mode `isotope` → fill mass number A, atomic number Z, symbol (case-normalized
  via `normalizeSymbol` / `ELEMENTS`) for a described isotope; mode `equation` → a nuclear equation with one or more
  missing particles (`{ left: [particle], right: [particle] }`, particle = `{ A, Z, symbol }` or named `alpha` / `beta` /
  `positron` / `gamma` / `neutron` / `proton`), student fills the missing ones; auto-grade per blank, and check A and Z
  are conserved. Widget renders stacked A/Z notation (sup/sub, mono) with inputs in place.
- **reaction** (Chemistry, "Predict products"): `{ reactants: 'AgNO3(aq) + NaCl(aq)', products: ['AgCl(s)', 'NaNO3(aq)'],
  requireStates: bool, requireCoefficients: bool, netIonic: bool }`. Student types the product side ("AgCl(s) + NaNO3(aq)").
  Parse into species with optional coefficient and state; order-free comparison using `formulasEqual`
  (js/lib/formula.js); partial credit = fraction of products right (no extras); states/coefficients checked only when
  required. Live preview like the formula widget.
- **vsepr** (Chemistry, "Molecular shape"): `{ formula, electronGeometry, molecularGeometry, bondAngle }` from fixed
  vocab lists (linear, trigonal planar, tetrahedral, trigonal bipyramidal, octahedral; bent, trigonal pyramidal, see-saw,
  T-shaped, square pyramidal, square planar…; angles 180, 120, 109.5, <109.5, 107, 104.5, 90, 90 & 120 …). Widget: three
  radio-card groups with small inline-SVG shape illustrations (simple ball-and-stick line drawings, tokens for colours).
  Credit per field (fields can be turned off by the teacher with `fields: ['electron','molecular','angle']`).
- **datatable** (Basics, "Complete the table"): `{ columns: [{ id, label, type: 'number'|'text', tolerance? }],
  rows: [{ id, cells: { colId: { value, given: bool } } }] }`; students fill the non-given cells; per-cell credit;
  numbers within the column tolerance; text normalized (trim, case-insensitive; formulas via `formulasEqual` when the
  column has `formula: true`). Widget = a real `<table>` with inputs, headers associated (scope / aria-label "Row X,
  Column Y"). Typical uses: protons/neutrons/electrons, ICE table.
