## Requirements (`render(root, ctx)`)
1. **Shell:** appHeader (title "ChemistryWorks", subtitle "Admin") with right side: "Open Google Sheet" link (`sheet-link`, href CONFIG.SHEET_URL, target _blank; disabled-looking with tooltip when empty) and `lock-admin` button (removes session `adminUnlocked` + `adminKey`, then `ctx.navigate('landing')`). Below: tab bar `tab-library`, `tab-builder`, `tab-analytics`, `tab-settings` (role=tablist, animated underline indicator sliding between tabs). Remember the last tab in sessionStorage key `adminTab`. Builder state persists while switching tabs within the session (keep it in module-level state; also autosave the in-progress builder test to localStorage key `builderWorking` so a refresh doesn't lose work).
2. **Library tab:** sections "Bundled (data/tests)" (from loadCatalog; for each, loadTest to show question count), "Drafts on this device" (getDrafts), "Published to Google Sheet" (listPublishedTests when CONFIG.GAS_WEB_APP_URL and adminKey exist; otherwise a hint linking to Settings). Each item `library-item-<CODE>` shows code, title, question count, total points, time limit; actions: `edit-<CODE>` (load into builder & switch tab), `preview-<CODE>` (`ctx.navigate('runner', { test, source, preview: true })`), `copy-link-<CODE>` (copies `${location.origin}${location.pathname.replace(/index\.html$/, '')}test?code=CODE`... simpler: `new URL('test?code=' + CODE, location.href.split('?')[0].replace(/[^/]*$/, ''))`; toast "Link copied"), duplicate (into builder with code + "_COPY"), delete (drafts: deleteDraft; published: deletePublishedTest with confirm modal). A `new-test` button starts a blankTest in the builder.
3. **Builder tab:** two modes toggled by `builder-mode-visual` / `builder-mode-json`.
   - Visual: settings card (code `test-code` auto-uppercase, title `test-title`, description `test-description`, time limit minutes `test-time-limit` (empty = untimed), toggles for shuffleQuestions, shuffleOptions, showResults, showCorrectAnswers, allowModeToggle, defaultMode select, passingPercent). Question list: each `question-editor` (data-index) is a collapsible card with header (number, type pill, points, truncated text preview) and actions `q-up`, `q-down`, `q-duplicate`, `q-delete` (confirm). Reorder animates (FLIP or simple transform transition). Body fields: `q-id`, `q-text` (textarea) with live rich preview below it (richText + renderMath, debounced 200ms), `q-points`, explanation textarea; per type:
     - mcq/multi: option rows `option-text-<i>` + `option-correct-<i>` (radio for mcq, checkbox for multi) + remove; `add-option`; multi has partialCredit toggle.
     - numeric: `numeric-answer` (accepts `6.022e23`), `numeric-tolerance`, toleranceType select, unit.
     - formula: `formula-answers` (comma-separated accepted answers) with live formulaToHTML preview chips; caseSensitive toggle.
     - truefalse: `tf-answer` segmented control/select.
     - matching: left rows `match-left-<i>` each with a select `match-correct-<i>` choosing the right item; right rows `match-right-<i>`; add/remove buttons for both; partialCredit toggle.
     Changing a question's type is not required (delete + add instead).
     `add-question` button opens a menu of 6 types (`add-question-<type>`); new question = `blankQuestion(type, nextQuestionId(questions))`, appended, expanded, scrolled into view, focus on its text.
   - JSON: `json-textarea` (monospace) showing `JSON.stringify(test, null, 2)`; `apply-json` parses it → on parse error show message with line/position; on success replace builder test (normalizeTest) and toast.
   - Always-visible sidebar/footer: `validation-errors` panel (attr `data-count`) listing `validateTest(normalizeTest(test)).errors` live (green "Ready to publish ✓" when 0), summary (question count, total points). Actions: `save-draft` (saveDraft(normalizeTest(test)); disabled with tooltip when invalid), `preview-test` (navigate runner preview with normalized test; allowed even with warnings only if valid), `download-json` (Blob download `<CODE>.json`), `import-json` (hidden file input; loads into builder), copy JSON, `publish-test` (requires GAS URL + adminKey; publishTest; result toast; disabled with explanation otherwise). Explain in a small note that bundling a test permanently = download JSON and commit to data/tests/ + add to index.json.
   - Keep the in-memory test as the single source of truth; re-render only the affected editor on input to avoid losing focus while typing (do NOT re-render the whole builder on each keystroke).
4. **Analytics tab:** source select `analytics-source` with options `device` ("This device", from getLocalResults()) and `sheet` ("Google Sheet", fetchResults with adminKey; option disabled with hint when not configured). Normalize both into ResultRow shape (device payloads: percentage string → number, timestamp = submitted_at). Filter by test `analytics-test-filter` (All + each code present). Empty state `analytics-empty`. Show:
   - KPI cards: `kpi-submissions`, `kpi-average` (mean % to 1 decimal, e.g. "82.4%"), `kpi-median`, `kpi-high`, `kpi-low`, plus avg duration.
   - `histogram`: 10 buckets (0–9, 10–19 … 90–100) as inline SVG or CSS bars animating height on render; bucket counts as labels; accessible (aria-label per bar).
   - `question-stats`: table per question (from responses): question text (truncated, rich), % correct, avg points, most common wrong answer (givenAnswerText); sort by hardest; color bar.
   - `results-table`: student name, email, test, score, %, duration, submitted time, tab switches; sortable columns (click header); `results-search` filters by name/email; click a row opens a modal with that submission's per-question responses.
   - `export-csv`: downloads current filtered rows as CSV (proper quoting of commas/quotes/newlines).
   - Refresh button for the sheet source.
   Pure helpers for stats (mean/median/histogram buckets/question aggregation/CSV) should be exported from admin.js (or js/views/admin/stats.js) as named exports so they can be unit-tested; write them DOM-free.
5. **Settings tab:** `admin-key-input` (password) + `save-admin-key` → session `adminKey`; `ping-backend` → pingBackend → `backend-status` text ("Connected · v1" / error); `setup-checklist` with live checks: Google Client ID configured, Apps Script URL configured, Sheet URL configured, Netlify Forms active (netlifyFormsEnabled from config.js), demo sign-in disabled in production (warn if ALLOW_DEMO_SIGNIN and no client id). Each item links to the matching DEPLOYMENT.md section. Show current CONFIG values (client id truncated).
6. **Polish:** smooth tab transitions (fade/slide 200ms), skeleton shimmer while loading library/analytics, empty states with icons, toasts for actions, focus management, responsive to 360px (builder sidebar collapses under content).
7. `render` returns a cleanup function removing any global listeners.
