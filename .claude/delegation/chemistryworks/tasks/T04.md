## Steps
1. `js/lib/submit.js` per contract. Use `crypto.randomUUID()` when available, else a fallback. `submitResults` must never throw; wrap each channel in try/catch. GAS: `fetch(gasUrl, { method:'POST', mode:'no-cors', headers:{'Content-Type':'text/plain;charset=utf-8'}, body: JSON.stringify(payload) })` → resolves = 'sent', rejects = 'failed'. Netlify: `fetch('/', { method:'POST', headers:{'Content-Type':'application/x-www-form-urlencoded'}, body: new URLSearchParams(toNetlifyFields(payload)).toString() })`. Run both channels concurrently. `flushOutbox` resends each queued payload (same submission_id) and removes the ones that succeed on at least one channel. Storage access must go through js/lib/storage.js (it works in Node without localStorage — it no-ops; for tests, provide a fake `globalThis.localStorage` before importing).
2. `js/lib/api.js` per contract. GET via `${gasUrl}?action=...` (use URL + searchParams). POST with text/plain JSON. Parse JSON; `{result:'success'}` → ok. Never throw.
3. `apps-script/Code.gs` per contract (V8 runtime, plain functions, no modules). Include: `VERSION` constant, `getSheet_(name, headers)` creating sheets with formatted headers, `doGet`, `doPost`, `handleSubmission_` (accepts direct payload or Netlify webhook `{data:{...}}` — parse `responses_json`/`flags_json` strings; coerce numbers), dedupe by scanning the Submission ID column (use `TextFinder` for speed), `LockService.getScriptLock().waitLock(10000)`, admin ops checking `PropertiesService.getScriptProperties().getProperty('ADMIN_KEY')` (if unset, admin ops return error 'admin_key_not_configured'), `publishTest` upsert by code (validate minimally: code, title, questions array), `getResults` returning ResultRow objects (parse JSON columns; percentage numeric), `json_(obj)` helper. Also a `setup()` function the teacher can run once from the editor to create both sheets and prompt to set ADMIN_KEY (log instructions). Write `apps-script/appsscript.json` manifest (timeZone "America/Los_Angeles", runtimeVersion V8, webapp access ANYONE_ANONYMOUS, executeAs USER_DEPLOYING).
4. `test/unit/apps-script.test.mjs`: load Code.gs into a `node:vm` context with in-memory fakes of SpreadsheetApp (spreadsheet with getSheetByName/insertSheet; sheet with appendRow/getLastRow/getRange(...).setFontWeight/setBackground/getValues/setValues, getDataRange, setFrozenRows, createTextFinder(...).matchEntireCell(true).findNext(), deleteRow), ContentService (createTextOutput(...).setMimeType → object exposing the text), PropertiesService, LockService, Utilities if used. Test: header creation, submission append with correct column order, dedupe, Netlify webhook shape, admin key rejection, publish/get/list/delete test, getResults parsing, ping, malformed JSON error. Keep fakes small but faithful to the calls Code.gs makes.
5. `test/unit/submit.test.mjs` and `api.test.mjs`: fake `fetch` recording calls; fake localStorage on globalThis (set before dynamic import). Test buildPayload fields/duration rounding/ISO dates, toNetlifyFields keys exactly match index.html's form inputs (read index.html and extract `name="..."` of inputs inside the form — compare sets, excluding bot-field), channel skipping rules, failure → outbox, flushOutbox success removes entries, localResults cap 500, api success/error/network-failure paths, correct URLs/actions/bodies.
6. `DEPLOYMENT.md`: complete, accurate, step-by-step guide for a teacher: overview diagram; 1) local run (`npm start`, demo sign-in, `npm test`, `npm run test:e2e`); 2) Google Cloud OAuth client (origins for Netlify domain + http://localhost:3000 + http://127.0.0.1:3000; consent screen; Internal for Workspace domains; restrict with ALLOWED_EMAIL_DOMAINS); 3) Google Sheet + Apps Script (paste Code.gs, optional appsscript.json via Project Settings "Show manifest", run `setup`, set ADMIN_KEY in Project Settings → Script properties, Deploy → New deployment → Web app, Execute as Me, Who has access: Anyone; copy /exec URL; how to update without changing the URL: Manage deployments → Edit → New version); 4) js/config.js values; 5) Netlify (import repo, no build command, publish `.`, Forms detection, enable form detection if disabled, optional outgoing webhook to the /exec URL — safe because of dedupe); 6) creating tests (admin panel `?admin=true`, bundled JSON vs Publish), test JSON reference (short; link to docs/ARCHITECTURE.md); 7) verifying end-to-end (checklist matching spec Phase 6); 8) troubleshooting (GIS origin mismatch error, `no-cors` opaque responses, Apps Script "Authorization required", sheet not updating after code change = redeploy new version, Netlify form not detected); 9) Limitations & security (answer keys client-side, admin code is UI-only, ADMIN_KEY protects data; recommend for formative assessment).
