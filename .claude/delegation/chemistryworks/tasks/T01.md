## Steps
1. `js/lib/formula.js`: implement normalizeFormula, formulaToHTML, formulaToLatex, formulasEqual exactly as specified. formulaToHTML must HTML-escape every character of input it emits (`<`, `>`, `&`, `"`, `'`).
2. `js/lib/schema.js`: QUESTION_TYPES, TYPE_LABELS, normalizeTest (deep copy, defaults, code uppercased + trimmed, options/left/right text coerced to strings, points coerced to number), validateTest, blankQuestion, nextQuestionId, blankTest. Validation must catch at least: missing/invalid code, missing title, no questions, duplicate question ids, invalid id chars, unknown type, empty text, points ≤ 0 or non-number, <2 options, duplicate option ids, mcq correctAnswer not an option id, multi correctAnswer empty / not array / unknown ids, numeric correctAnswer not finite, negative tolerance, bad toleranceType, formula correctAnswer empty, truefalse correctAnswer not boolean, matching <2 left or right, correctAnswer missing a left id or pointing to unknown right id, timeLimitMinutes not positive, passingPercent out of 0–100, defaultMode invalid. `blankQuestion(type,id)` output must pass validation once given non-empty text (it should already contain placeholder text so it validates as-is).
3. `js/lib/grading.js`: parseNumber, isAnswered, gradeQuestion, gradeTest, formatAnswer per the scoring rules. Must import from formula.js. Never throw on malformed answers (wrong type for question → treated as incorrect/unanswered, not an exception).
4. Unit tests with `node:test` + `node:assert/strict`, ES module imports via relative paths (e.g. `import { gradeTest } from '../../js/lib/grading.js'`). Aim for thorough coverage: every question type correct/incorrect/unanswered/partial, every parseNumber format in the contract plus junk input (`"abc"`, `""`, `"1.2.3"`), unit stripping, tolerance edge (exactly at boundary passes), percent tolerance with negative keys, formula normalization table (≥15 cases incl. hydrates, charges, unicode sub/superscripts, parentheses, case-insensitive flag), formulaToHTML table + XSS escaping, schema validation table (one test per error rule), normalizeTest non-mutation, CHEM101 fully correct answers → 100.00, all wrong → 0.00, mixed → exact expected percentage string, total 0 guard.
5. Run the acceptance commands and fix failures in owned files.
