## Deviations from the spec
- Interpretation choices (contract ambiguous): numeric formatAnswer appends unit to numbers too ("18.016 g/mol"); formula array formats as all accepted joined " / ".
- normalizeFormula treats a trailing digit(s)+sign at species end as a charge ("SO42-" -> "SO4^2-", "Fe3+" -> "Fe^3+", also "H2+" -> "H^2+", "O2-" -> "O^2-"). Charge-sign detection requires a species boundary (end, whitespace, . , ; ( ) ] ->), so "Na++Cl-" without spaces is not converted.
- formulaToLatex converts hydrate "." to "*" (mhchem syntax) and strips whitespace via normalizeFormula.
- normalizeTest: preserves unknown extra fields (drafts carry updatedAt); coerces numeric-looking string correctAnswer for numeric questions to a number; trims title.
- validateTest also flags empty option/left/right text, invalid option ids, extra unknown left ids in matching correctAnswer.
- isAnswered is type-aware (e.g. truefalse needs boolean, false counts as answered; matching {a:''} is unanswered).
- blankQuestion throws RangeError on an unknown type. Defaults: multi correct ['a','b']; matching ids l1/l2/r1/r2.
