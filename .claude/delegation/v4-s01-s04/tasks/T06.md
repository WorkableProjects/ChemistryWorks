## Build
- **Sticky top bar:** the navy `appHeader` stays; below/inside it a calm runner bar with test title, timer (mono; danger state), and a progress bar that eases forward (`transform: scaleX` on a teal fill, `--dur-slow`). Remove decoration during the test: solid `--bg`, question card on `--bg-elev`.
- **Question navigator:** on desktop (≥ 1024px) a **collapsible side rail** (left) listing question tiles (answered = filled teal-tinted, flagged = flag icon, current = ring; never colour alone — keep existing markers/text), with a collapse toggle remembered per device (`localStorage` key `cw:navRail` via `js/lib/storage.js` `load/save('navRail', …)`). On phones/tablets (< 1024px) the existing drawer becomes a **bottom sheet** (slides up, backdrop fades, drag handle visual, Escape/backdrop closes, focus trapped/returned as today). Keep the existing drawer testids and the "Questions" button.
- **Reference pane** (`reference-pane.js`): a right-side **drawer** (slides in from the right over/beside content on desktop; full-height sheet on phones), same testids and contents.
- **Question card:** generous spacing, display-font question number row, pills for type/points; navigator dots fill when answered.
- **Motion:** question-to-question slide (the existing focus-mode enter/leave classes — restyle with token durations, translateX ≤ 24px + opacity), gentle shake on an invalid answer if the code already flags one (don't add new validation), button press-down. Off under reduced motion.
- Footer bar: answered count, Saved indicator, shortcuts, Submit — restyled, same testids.
- Phones (360px): no horizontal scroll; header right side must not overflow (icons only).
