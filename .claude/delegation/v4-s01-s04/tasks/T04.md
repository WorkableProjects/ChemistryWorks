## Build
- **Hero** with the wordmark (`brandLogo('wordmark')`, keep `data-testid="landing-logo"`), a one-line intro using the full name ("ChemistryWorks — chemistry tests, study and games" or similar), cool `--bg` surface. Optional subtle decorative molecule/hex pattern in the hero only (inline SVG, `aria-hidden`, hidden under `@media (prefers-contrast: more)`). Keep the drifting bubbles if they still fit (they use `--brand-teal-soft`), but make sure they stay subtle.
- **Code entry is the main action** (signed in): large mono code input + "Start test" primary button, same testids (`code-card`, `code-input`, `code-submit`, `code-error`, `code-retry`). Signed out: the sign-in card (`signin-card`, `google-signin`, `demo-name`, `demo-email`, `demo-signin`, `signin-error`).
- **"Continue where you left off"** (`resume-list`, `resume-<code>`) and **"Your tests"** as cards: merge in-progress attempts and submitted results (`past-results`, `view-feedback-<id>`) into a "Your tests" card grid/list with status badges: **In progress** (pill--primary), **Submitted** (pill--warning or neutral), **Released** (pill--success) — Released when the local result has released feedback (inspect the result payload fields; if there is no released flag locally, show Submitted and leave a code comment). Keep the existing testids on the same actionable elements.
- **Version label:** small muted `v${SITE_VERSION}` under the sign-in / code card (`data-testid="site-version"`).
- Top-right: admin link (`admin-link`) + settings (`themeControl()`), styled for the light page (not the navy header).
- Footer: "© ChemistryWorks".
- Motion: hero/panel rise on load; cards stagger (`stagger`), hover lifts cards 1–2px; nothing under reduced motion.
- Desktop: hero left / card right two-column is acceptable, or centered stack — your call, but the code card must be the visual focus. Phones: single column, no horizontal scroll at 360px.
