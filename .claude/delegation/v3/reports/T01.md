## Deviations
1. test/unit/schema.test.mjs:17 asserted the exact QUESTION_TYPES list; it cannot pass with new types, so I appended the 4 new types to the expected array. Nothing weakened or removed.
2. ptable gets an optional `partialCredit` (default false) so "same rules as multi incl. partial credit" works; not in the spec's JSON shape but backward compatible.
3. ptable answers are normalized to canonical symbol case (`na` -> `Na`); `multiple:false` requires exactly one answer.
4. data/tests/index.json was `[]`; it now has only the DEMOV3 entry.
5. `.adm-grid--2` did not exist in admin.css (not owned), so it is defined in css/qtypes.css.
6. balance partial credit with allowMultiples: best match over k * lowest ratio (k = 1..max entered); without it, positions vs `coefficients`. Balance text shows coefficient 1 as omitted and a blank as `_`.
7. econfig: orbitals must be space-separated unless superscripts/^ are used (`1s22s2` is not split). A missing count (`3s`) is read as 1.
8. sigfigs: an all-zero number counts as 1 sig fig. Unparseable input scores 0 even with partial credit.
