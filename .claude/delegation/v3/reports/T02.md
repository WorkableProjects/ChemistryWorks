## Notes on behavior
- Registry: GAMES = classic, survival, lightning, elementhunt, matchup, flashcards. `playableGames(test)` -> [{game, playable, reason, questions, note}], honors `test.games` (empty/unknown -> all). `loadBest/saveBest(email, code, gameId)`; classic falls back to old key.
- Picker flow: mode-select "Game mode" (testid `mode-game`) -> picker (`game-picker`, cards `game-pick-<id>`, unplayable disabled with reason). Params `picker: true` opens it directly; game end screen "Back to games" (`game-back`) uses that and passes studyBlocked back.
- Shared shell keeps all old testids (game-score, game-streak, game-points, game-feedback, game-next, game-end, game-final-score, game-again, game-to-study, game-home, game-review, etc.).
- Survival: 3 lives, +1 life per 5 correct in a row (cap 3), sorted by points asc. Lightning: 60 s total, skip -2 s, mcq/truefalse/numeric. Element Hunt: 10 prompts x 20 s, roving-tabindex arrow-key table. Match-Up: 6 pairs, memory flip cards. Flashcards: unscored, review cards return after 3 cards; keys K/R/Space.
- Sound: off by default, HUD toggle `game-sound`, stored via storage.js `save('gameSound')` (localStorage key `cw:gameSound`).
- Animations: transform/opacity (plus stroke-dashoffset on the ring, updated from JS), CSS-var durations with fallbacks, disabled under prefers-reduced-motion AND :root[data-motion="reduce"]; JS also checks data-motion="reduce".
