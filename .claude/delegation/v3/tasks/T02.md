# T02 — Game picker + new games (V3-04)

Read docs/v2.5/v3.0plan.md section "V3-04" and V3-06 "Games" bullet first. Repo: static ES-module app, no build, no deps.

## Goal
1. Refactor game mode into a registry: `js/lib/games/index.js` exports `GAMES` (ordered array) and helpers
   `playableGames(test)` → `[{ game, playable: bool, reason: string, questions }]` honoring optional `test.games`
   (array of ids; default all). Each module `js/lib/games/<id>.js` exports
   `{ id, title, blurb, icon, playableTypes, minQuestions, scoring helpers }` (pure logic, no DOM).
   Existing logic in js/lib/game.js moves/re-exports as `classic` (keep js/lib/game.js exports working — existing tests in
   test/unit/v25-game.test.mjs import it).
2. Best score key `gamebest:<email>:<code>:<gameId>`; for classic also read the old key `bestKey(email, code)` as fallback.
3. `js/views/game-shell.js`: shared HUD (score, streak flame, countdown ring, lives hearts slot) + end screen
   (score, best, play again, back to games). `js/views/game.js` becomes the dispatcher: params `{ test, source, gameId }`
   (default 'classic'), renders the board for that game inside the shell. Board renderers may live in
   `js/views/games/<id>.js`.
4. `js/views/mode-select.js`: "Game mode" opens a picker (cards: icon, title, blurb, best score; unplayable ones disabled
   with the reason). KEEP `params.studyBlocked` behavior (hides Study mode) already in the file.
5. New games: Survival, Lightning Round, Element Hunt (uses js/lib/elements.js data; periodic table board — may copy layout
   from js/views/reference-pane.js periodicTable(), read-only), Match-Up (pairs from `matching` questions + element
   symbol↔name), Flashcards (study, not scored). Mechanics exactly as in the plan table.
6. Animations (css/game.css): correct/wrong flash, "+850" points pop, streak flame grows, countdown ring, hearts lose
   animation, card flip. transform/opacity only; durations via CSS vars `var(--dur-fast,120ms)`, `var(--dur-base,240ms)`,
   `var(--dur-slow,400ms)`, `var(--ease-out,cubic-bezier(.2,.8,.2,1))`, `var(--ease-spring,cubic-bezier(.34,1.56,.64,1))`
   (another agent defines these tokens in base.css; always include the fallback). Disable under
   `@media (prefers-reduced-motion: reduce)` AND under `:root[data-motion="reduce"]` selectors.
7. Optional sound: `js/lib/games/sound.js` Web Audio short tones, off by default, mute toggle in HUD, saved in
   localStorage key `gameSound`. No audio files.
8. Keyboard + touch for every game; aria-live region for score/feedback.
9. No game ever calls the backend, submit.js, or fetch.
