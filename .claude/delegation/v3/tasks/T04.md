## Types (decided)
- categorize: `{ type:'categorize', categories:[{id:'ionic',label:'Ionic'},…], items:[{id:'i1',text:'NaCl',category:'ionic'},…], partialCredit:true }`.
  Widget: each item is a card; student assigns it to a bin. MUST work without drag: each item has a <select> (or a row of
  radio-like buttons) to choose the bin; drag-and-drop (pointer events) is an optional enhancement. Answer: `{ itemId: categoryId }`.
  Grading: all correct = full; partialCredit → fraction of items correct. Shuffle item order if test.shuffleOptions.
- hotspot: `{ type:'hotspot', image:{url,alt}, labels:[{id:'a',text:'Beaker',x:0.32,y:0.61}], radius:0.06, partialCredit:true }`
  (x,y,radius are fractions of image width). Widget: image with the label chips; student selects a label then clicks/taps
  the image to place it; keyboard alternative: after selecting a label, arrow keys move a crosshair (step 0.02) and Enter
  places it. Answer: `{ labelId: {x,y} }`. Grading: a label is correct if distance ≤ radius. Builder editor: label list with
  numeric x/y inputs plus "click on preview image to set" for the selected label.
- graph: `{ type:'graph', mode:'read'|'plot', chart:{ xLabel, yLabel, xMin,xMax,yMin,yMax, series:[{points:[[x,y],…]}] }, … }`.
  mode 'read': show the chart (inline SVG you render), student answers a number: fields `answer`, `tolerance` (reuse numeric grading
  helper from grading.js). mode 'plot': student clicks to add points on an empty grid (click a point to remove; keyboard: arrow
  keys move cursor, Enter adds), fields `targets:[[x,y],…]`, `toleranceX`, `toleranceY`; correct if every target has a placed point
  within the tolerance box and no extra points beyond targets.length; partialCredit fraction of targets hit. Answer: `[[x,y],…]`.
- Add a sample of each to data/tests/DEMOV3.json; docs/guide.md section per type with JSON example.
