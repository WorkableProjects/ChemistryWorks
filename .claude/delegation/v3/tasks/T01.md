## Type specs (decided — do not redesign)
- balance: `{ type:'balance', reactants:['H2','O2'], products:['H2O'], coefficients:[2,1,2], allowMultiples:false, partialCredit:false }`.
  Widget: a number input before each formula (formulas rendered with formulaToHTML from js/lib/formula.js), "+" between, "→" between sides.
  Answer shape: array of positive integers (blank = 0/unanswered). Correct: equals coefficients exactly; if allowMultiples, any
  positive integer multiple k*coefficients. partialCredit: fraction of positions matching the lowest-ratio coefficients.
  Validation: reactants/products non-empty string arrays, coefficients positive integers, length = reactants+products.
- econfig: `{ type:'econfig', answers:['1s2 2s2 2p6 3s1','[Ne] 3s1'] }`. Input text with live superscript preview
  (e.g. "2p6" → 2p⁶). Normalize: trim, collapse spaces, accept superscript digits or ^, case-insensitive subshell letters,
  expand noble-gas cores ([He],[Ne],[Ar],[Kr],[Xe],[Rn]) to full form, then compare orbital→count maps (order-insensitive).
  Correct if matches any entry in answers. Put the parser in js/lib/qtypes/econfig.js (pure, unit-test-friendly).
- ptable: `{ type:'ptable', answers:['Na','K'], multiple:true }`. Widget: clickable periodic table. Reuse element data in
  js/lib/elements.js (read it) and look at js/views/reference-pane.js periodicTable() for layout (read-only; you may copy
  layout logic into js/views/widgets/ptable.js). Buttons must be real <button>s with aria-pressed and aria-label (element
  name). Grading: same set rules as `multi` (read how multi grades incl. partial credit). multiple:false = single select.
- sigfigs: `{ type:'sigfigs', answer:0.00450, sigFigs:3, tolerance:0.000001, partialCredit:true }`. Student types a number
  string (scientific notation like 4.50e-3 or 4.50×10^-3 allowed). Grade: value within tolerance (absolute) AND sig-fig count
  of the typed string equals sigFigs. partialCredit: half points for each part. Keep the raw string as the answer.
  Sig-fig counting in js/lib/qtypes/sigfigs.js (trailing zeros after decimal count; trailing zeros in integers without a
  decimal point are ambiguous → count as not significant).
