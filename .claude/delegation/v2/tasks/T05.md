# T05: Export one reviewed submission as print/PDF (V2-08)

**Agent:** executor-sonnet · **Wave:** 2 · **Depends on:** T02 (diagram renderers), T04 (grader button)

## Goal
From the grader (`export-pdf` button, already wired by T04), staff get a clean printable document of one
student's reviewed submission — student name, assessment name, total score, section headings, every
question's prompt, the student's answer (orbital and Lewis diagrams legible, including brackets/charges),
per-question score, and comments when allowed — and the browser's "Save as PDF" proposes a meaningful filename.

## Interfaces
```js
// js/lib/export.js
export function exportFilename(row) // "ChemistryWorks - Ada Lovelace - CHEMV2 Electrons & Bonding"
//  student name (fallback: email, then "Student"), code, title; strip characters illegal in filenames
//  (\ / : * ? " < > |) and control chars, collapse whitespace, max 120 chars. No extension (browsers add .pdf).
export function buildExportModel({ row, test, includeComments })
// -> { title: exportFilename(row), studentName, studentEmail, testCode, testTitle,
//      score: { earned, total, percentage /* number, 1 decimal */ , pending /* count of needsGrading */ },
//      groups: [{ section: { id, title, instructions } | null, items: [{
//         number /* 1-based display number */, questionId, type, prompt /* questionText */, question /* test question or null */,
//         answered, answerText, givenAnswer, pointsEarned, pointsPossible, needsGrading, comment /* string|'' */ }] }] }
//  - Order & grouping: with a test → groupQuestions(test, { skipEmpty: true }) order, items matched by questionId
//    (responses for questions missing from the test are appended at the end in an unsectioned group);
//    without a test → responses in stored order, one unsectioned group.
//  - comment = includeComments ? (row.comments[qid] || '') : ''   — never include comments when includeComments is false.
// js/views/admin/export-view.js
export function printSubmission({ row, test, includeComments }) // renders + window.print(); returns the root element
export function exportDocument(model) // -> HTMLElement (used by printSubmission; exported for tests)
```

## Decisions already made
- Rendering: `exportDocument` builds an `article.export-doc` (`data-testid="export-doc"`): header with
  "ChemistryWorks" small caps label, test title (h1), student name + email, total score
  `export-score` ("8.5 / 12 · 70.8%", monospace; if pending > 0 add "· 1 answer not yet graded"), a
  thin rule; then per group an `h2.export-section` (`export-section`) with instructions (richText); each item
  `section.export-item` (`export-item-<qid>`, `break-inside: avoid`): "Q<n>" + points "1.5 / 2 pts"
  (or "— / 2 pts (not graded)"), prompt (richText), "Answer" block — diagram for orbital / structure / lewis
  types when `question` is available (`orbitalDiagram`, `structureDiagram` with `size:'md'`, `lewisDiagram`)
  followed by the answer text; plain text otherwise (pre-wrap for short/open) — and, when `comment`, a
  "Teacher comment" block rendered with `commentBody`. Unanswered → "Not answered".
- No correct answers, explanations, rubrics, timestamps or private teacher notes in the export (v1 scope).
- `printSubmission`: ensure a `<div id="print-root">` exists as a direct child of `body` (create once),
  replace its content with `exportDocument(model)`, `renderMath(root)`, set `document.title` to
  `model.title` (restore the old title on `afterprint`, and also after a 1s timeout fallback),
  add `body.is-printing`, call `window.print()`, remove the class on `afterprint`.
- `css/print.css`: `#print-root` hidden on screen. `@media print`: when `body.is-printing`, hide every other
  child of body (`body.is-printing > *:not(#print-root) { display:none !important }`), show #print-root;
  `@page { margin: 16mm }`; black text on white, 11pt readable serif or the body font; diagrams keep
  their SVG strokes black (override diagram colour tokens inside `.export-doc`), monospace for scores; avoid
  page breaks inside items. Use plain colours here only inside @media print (exception to the token rule:
  print is always black on white).
- Security: only `h()`/`richText()`/`commentBody()`; no innerHTML of row data.

## Steps
1. `js/lib/export.js` + `test/unit/export.test.mjs` (filename sanitizing incl. `"Ada/Lovelace:*"`, missing
   name; grouping with/without test; includeComments false strips comments; pending count; numbering).
2. `export-view.js` + `print.css`.
3. E2E `test/e2e/v2-export.test.mjs`: reach the grader with a mocked released row for CHEMV2 (copy the setup
   from v2-grading.test.mjs), stub `window.print` via `page.addInitScript(() => { window.__printed = 0; window.print = () => { window.__printed++; }; })`,
   click `export-pdf`, assert `__printed === 1`, `#print-root [data-testid=export-doc]` contains the student
   name, `export-score`, 2 `export-section`s, an SVG diagram for the orbital and structure items, the comment
   text; `document.title` was set to the filename at print time (capture it inside the stub). Second case: an
   unreleased row → no comment text in the document. Emulate print media
   (`page.emulateMedia({ media: 'print' })`) and assert the app header is hidden and `#print-root` visible.
4. Run acceptance.
