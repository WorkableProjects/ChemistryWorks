## Goal
Apply a whole-app Lab-notebook visual direction through reusable design tokens: warm off-white paper
surfaces, ink-blue text, subtle graph-paper accents, monospace for formulas/numbers/scores, a readable body
face. Full treatment on student screens (landing, runner, results, feedback), toned-down in instructor/admin
views. WCAG AA contrast, visible focus, no colour-only status, responsive, nothing distracting during tests.

## Decisions already made
1. **Tokens** (in base.css `:root`, keep every existing token name working; add new ones):
   - Paper/ink neutrals (light): `--bg` warm paper ≈ `#F6F2E8`, `--bg-elev` ≈ `#FFFDF7`, `--bg-sunken` ≈
     `#EEE8DA`, `--border` ≈ `#DCD3C0`, `--border-strong` ≈ `#C3B79F`, `--text` ink blue ≈ `#1B2A4A`,
     `--text-muted` ≈ `#3F4B66`, `--text-faint` ≈ `#596381`. Tune values so the contrast test passes.
   - New: `--paper`, `--ink` (aliases), `--grid-line` (graph-paper line colour, very low alpha ink),
     `--grid-major` (every 5th line, slightly stronger), `--grid-size: 24px`, `--margin-rule` (a muted red
     notebook margin line, decorative only), `--texture` (the composed graph-paper background-image),
     `--texture-strength` (`1` full / `0.5` toned / `0` none), `--font-body`, `--font-display`
     (headings; may equal body), `--font-mono`; keep `--font` = `var(--font-body)` and `--mono` =
     `var(--font-mono)`.
   - Spacing scale: `--space-1 … --space-8` (4, 8, 12, 16, 24, 32, 48, 64 px). Use them in new/edited rules.
   - Intensity levels: `:root[data-role="student"]` = full (`--texture-strength: 1`),
     `:root[data-role="admin"]` = toned down (`--texture-strength: 0`, no grid anywhere behind content;
     at most the decorative margin rule in the header). Dark mode ("notebook at night"): warm dark neutrals,
     light ink-blue-white text, grid lines very faint; accents keep working.
   - Accent palettes stay (user choice). Re-tune `blue` (student default) toward an ink blue (≈ `#2348A4`) so
     it harmonises with the paper; others may be lightly tuned for AA on paper.
2. **Fonts** (Google Fonts, one `<link>`; replace Plus Jakarta Sans): body **Atkinson Hyperlegible**
   (400/700, italic 400), mono **IBM Plex Mono** (400/500/600); display may be Atkinson Hyperlegible 700.
   Keep `display=swap` and system fallbacks.
3. **Texture rules**: graph paper only on the page background and decorative areas (landing hero, page
   gutters around the runner, empty states). Never behind question text, answers, inputs, tables or
   form fields: question cards, inputs, reference pane panels, tables are solid `--bg-elev` / `--bg-sunken`.
   In the runner the grid is faint (`--texture-strength` ≤ 0.6 effective alpha) and static (no animation).
   Respect `prefers-reduced-motion` and `prefers-contrast: more` (disable texture, stronger borders).
4. **Monospace** for: formulas and formula inputs, numeric inputs, scores/points (`score-points`,
   `score-percentage`, `results-item__pts`, grading points inputs and totals, `feedback-score`,
   `submission-count-*`, timer, periodic-table masses/numbers, orbital sublevel labels, test codes).
5. **Status without colour alone**: verify that correct/incorrect/partial/pending, override, released,
   validation errors, flagged/answered navigator tiles all have an icon or text besides colour; if one
   relies only on colour, add a CSS-only cue (e.g. border style, `::before` text/glyph) and list it.
6. **Focus**: a single consistent `:focus-visible` style (2px solid `--primary` + 2px offset, also on SVG
   bonds/atoms/orbital boxes via `outline` or a stroke), never removed.
7. **Admin density**: do not increase paddings/row heights in admin tables/lists (≥ existing density).
8. `docs/DESIGN.md`: the token table (name, light value, dark value, purpose), intensity levels, typography
   scale, spacing scale, texture rules, component notes (cards, buttons, pills, inputs, tables, reference
   pane, diagrams), accessibility rules, and "how to add a new view" guidance.
