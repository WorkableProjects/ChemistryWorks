## Goal
Teachers can, in the existing visual builder (`?admin=true` → Builder tab): create/rename/reorder/delete named
sections with instructions, assign each question to a section (or none), see each section's calculated point
total; add per-test reference resources; author `orbital` questions; and turn on student-drawn brackets &
charges for Lewis structures (with reference-key charges). Everything round-trips through JSON mode,
drafts, preview and publish.

## Decisions already made
1. **Sections panel** (in the test-settings area above the question list): card titled "Sections"
   (`data-testid="sections-editor"`). Rows per section: title input `section-title-<i>`, instructions
   textarea `section-instructions-<i>` (richText/KaTeX allowed; hint says so), calculated points label
   `section-points-<i>` ("4 pts · 2 questions" — computed with `sectionPoints`, never editable), move up/down
   `section-up-<i>` / `section-down-<i>`, delete `section-delete-<i>` (confirm dialog; its questions become
   unsectioned — never delete questions). Button `add-section` adds `{ id: nextSectionId, title: 'Section N',
   instructions: '' }`. Hint text: "Section totals are calculated from their questions."
2. **Question → section**: each question editor gets a select `q-section` ("No section" + section titles).
   Changing it sets/deletes `q.section` and then reorders `S.test.questions = orderQuestions(S.test)` so the
   list always shows canonical order. The question list renders a group header before each section's
   questions (`data-testid="builder-section-<id>"`, title + calculated points); unsectioned group first.
   Existing `q-up`/`q-down` move a question within its group only (disable at group edges).
   A new question (`add-question-<type>`) gets the section of the current last question in the list (so building
   section by section works; none when the list is empty), then the list is reordered.
3. **References panel** (`data-testid="references-editor"`): add buttons `add-reference-periodic-table`
   (disabled when one exists), `add-reference-text`, `add-reference-image`. Row per reference: type label,
   title input `ref-title-<i>`, for text: textarea `ref-content-<i>`; for image: `ref-url-<i>`, `ref-alt-<i>`
   with a small preview img when `safeImageUrl` passes; `ref-up-<i>`, `ref-down-<i>`, `ref-delete-<i>`.
   Hint: "Shown to students in a side pane while they take the test."
4. **Orbital editor** (`case 'orbital'` in the type editor dispatch): select `orbital-max` listing `AUFBAU`
   ("Up to 3d"); checkboxes `orbital-type-s|p|d|f`; a live note listing the sublevels shown
   (`sublevelsFor(q).join(' ')`, `data-testid="orbital-sublevels"`); a "Sample answer (optional, for
   graders)" area rendered with `orbitalWidget(q, { get: () => q.sampleAnswer, set: (_, v) => { q.sampleAnswer = v ?? null; changed(); } })`
   plus a `orbital-sample-clear` button. Changing range re-normalizes the sample via `normalizeOrbitalAnswer`
   (drop it to null when it ends up empty). Note text: "Orbital diagrams are graded by the teacher."
   Add `orbital` to the add-question type menu (it is in `QUESTION_TYPES`, so check how the menu is built).
5. **Lewis structure editor**: `switchEl` "Student draws brackets & charges (teacher graded)"
   `data-testid="structure-student-charges"` toggling `q.studentCharges`. When on, show under the existing key
   editor: key bracket checkbox `structure-key-bracket`, key overall charge number `structure-key-charge`
   (−4..4), and per atom a formal-charge number input `atom-fc-<i>` (−4..4) — all writing into
   `q.correctAnswer` (for an array of resonance forms, edit the first form; follow how the existing editor
   handles the key). Zero values are stored by omitting them (`formalCharges` only has nonzero atoms;
   `bracket` omitted when false, `charge` omitted when 0). Existing preview (`structure-preview`) must reflect
   the charges (T02 updates `structureDiagram`).
6. JSON mode, Save draft, Preview, Download and Publish already serialize `S.test`; make sure `sections` and
   `references` survive (blankTest now includes them; old drafts without them must still open).
