## What to cover (at minimum)
- orbital: `sublevelsFor` defaults, `maxSublevel` '3d' with s,p,d → `1s 2s 2p 3s 3p 4s 3d`; types filter
  (only 'p' up to 3p → `2p 3p`); `normalizeOrbitalAnswer` pads/truncates boxes, maps 'du'→'ud', drops unknown
  sublevels and junk; `orbitalElectronCount`; `isOrbitalAnswered`; `describeOrbital` text; `boxLabel` strings
  say "spin up"/"spin down"; `validateOrbital` errors (bad maxSublevel, empty types, sample with unknown
  sublevel / too many boxes / bad state).
- sections: `orderQuestions` (unsectioned first; section order; stable inside groups; unknown section ids
  treated as unsectioned); `groupQuestions` points and `skipEmpty`; `sectionPoints`; `sectionOf`;
  `nextSectionId`/`nextReferenceId`; `safeImageUrl` (https ok; http, javascript:, data:, //host rejected;
  relative path ok); `referenceTitle` fallback.
- comments: `cleanComment`/`cleanComments` (trim, cap 2000, drop empty/whitespace, non-object input);
  `safeHref` (https/http/mailto ok; javascript:, data:, vbscript:, relative, URLs with spaces/quotes/`<`
  rejected); `parseComment` bold/italic/links/bare URLs (trailing punctuation excluded), unsafe link text kept
  as plain text, lists (ul/ol, switching), paragraphs + line breaks, `snake_case` and `2*3*4` not italicised,
  HTML-looking input stays as text nodes; `commentToText`.
- schema: v2 defaults (`sections: []`, `references: []`; questions without section have no `section` key);
  normalizeTest reorders to canonical order and never mutates input; validation errors: unknown question
  section, duplicate section id, missing section title, bad reference type, text ref without content, image
  without alt / unsafe url, two periodic tables; orbital `blankQuestion` is valid; `isManualQuestion` for
  short/open/orbital/structure±studentCharges/mcq; CHEMV2 fixture valid.
- grading: orbital & studentCharges structure → `needsGrading` when answered, 0 when unanswered,
  `manual:true`; mcq `manual:false`; `sectionId` present only for sectioned questions; `pendingCount`.
- structure charges: `normalizeChargeMarks` clamps to ±4 and fills atoms; `normalizeStructureAnswer` adds the
  fields only with studentCharges; `isStructureAnswered` true for bracket-only / charge-only;
  `describeStructure` mentions brackets and formal charges (e.g. "N 1+"); `chargeLabel` (1 → "+", -2 → "2−",
  explicit → "1−", 0 → ""); validation of key bracket/charge/formalCharges types.
- api: `saveGrade` sends `comments`/`release` only when provided; `fetchSubmissionCounts` ok/error shapes;
  `fetchFeedback` passes `submissionId` + `studentEmail`, no adminKey, maps released true/false, never throws
  on network failure.
