## Deviations from the spec
- `referencePane()` returns `{ el, toggle(), destroy() }` (extra `toggle()` used by the R shortcut); still null with no references.
- Without references the runner renders `main.runner-main` directly (no `runner-split` wrapper), so tests without references are unchanged.
- Resizer lives inside `aside.ref-pane` (absolutely positioned on its left edge) rather than as a separate grid child; it is still between questions and pane visually.
- Elements: group/period/category are derived in code from a compact symbol/name/mass table, exported as the plain ELEMENTS array. At is classed as halogen; Zn/Cd/Hg/Cn as transition-metal.
- Section pill text = title before the first ":" (e.g. "Part A"), full title otherwise.
- Pane width/collapsed state: `--ref-w` and `data-ref-collapsed` are set on `.runner-split` (the pane applies them after being appended, via queueMicrotask).
