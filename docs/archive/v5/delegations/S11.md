# S11 — Question types I (V5-07)

All three run in parallel. Read first: `js/lib/qtypes/registry.js`, `js/views/qtypes/registry.js`, one complete
existing type as the pattern (`js/lib/qtypes/molarmass.js` + `js/views/qtypes/molarmass.js`), and contract → New
question types. Each type:
- Definition `js/lib/qtypes/<type>.js` (pure: normalize, validate, blank, isAnswered, score, answerText, keyText,
  correctAnswer) + UI `js/views/qtypes/<type>.js` (widget, editor, review). Register via one import line each in
  `js/lib/qtypes/v4-types.js` and `js/views/qtypes/index.js`; label in `TYPE_LABELS`; group in the builder picker.
- CSS in `css/qt-<type>.css` (+ one `<link>` in `index.html`). Hidden from the builder unless `feature('v5Types')`.
- Algorithmic variable support (`js/lib/algorithmic.js`) where noted.
- Works in results, grading, CSV/PDF export (`answerText`/`keyText`/`review`), and every game mode (it does if the
  widget follows the contract).
- One example question in `test/fixtures/v5/<type>.json`; unit tests `test/unit/v5-qt-<type>.test.mjs` (normalize,
  validate errors, scoring incl. partial); e2e `test/e2e/v5-qt-<type>.test.mjs` (answer in runner → graded result).
  E2E loads the fixture through the helpers' test-override route.

## S11a — `ionicformula` (Ionic compound builder)
**Model:** sonnet · **After:** W0
Student drags (or taps, for keyboard/touch) cation and anion tiles — including polyatomic ions — into a tray until
charges balance; live formula (subscripts, parentheses for polyatomics ×2+) and optional name field. Teacher sets the
ion bank (common ions list in the editor + custom), target compound, whether name is required. Score: formula match
(order-insensitive tile counts reduced to lowest ratio), name via the naming helpers from `js/lib/qtypes/naming.js` if
required (partial: 0.5 each). Algorithmic: pick target from a list.

## S11b — `ionbuilder` (Ion / atom builder)
**Model:** haiku · **After:** W0
Two modes set by teacher: (a) given symbol + mass number + charge, student sets protons / neutrons / electrons with
steppers; (b) given particle counts, student writes symbol, mass number, charge. Element data from `js/lib/elements.js`.
Score: exact per field, fraction = fields right / fields. Algorithmic: random element from a teacher list + charge.

## S11c — `isotopemass` (Average atomic mass)
**Model:** sonnet · **After:** W0
Modes: (a) table of isotopes (mass, % abundance) given → compute average; (b) average given + one abundance missing →
find it; (c) student fills the table from given data then computes. Show work rows optional. Score: numeric with
teacher tolerance (default ±0.01 amu / ±0.1 %), partial per row in mode (c). Validate abundances sum to 100 ± 0.01.
Algorithmic: perturb masses/abundances within limits keeping the sum 100.
