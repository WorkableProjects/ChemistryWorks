# S07 — Class Hub front end (V5-10)

Backend is done (B3). Both agents run in parallel; behind `feature('classHub')`.

## S07a — Teacher side
**Model:** sonnet · **After:** B3, S08b · **Plan:** V5-10 "Teacher side"
**Owns:** `js/views/admin/hub/` (new), `js/views/admin/classes.js` (add tabs/links only), `css/hub.css` (new, teacher
rules under `.hub-admin`), admin route entries in `js/views/admin/shell.js`

Use the data store (`js/lib/store.js`, resource `hub`) and optimistic updates like the library.
1. Class page tabs: **Stream** · **Assignments** · **Roster**.
2. **Assign** dialog: tests from the library, one or more classes, opens / due (date+time), late allowed, instructions,
   allowed modes (from `modesForTest`), required vs optional, publish later. **Copy to class** on each assignment.
3. **Stream:** post text / link / image (reuse `js/lib/image-upload.js`), pin one, delete; assignment posts shown.
4. **Tracker** per assignment: roster grid with status chips, filters, % and last mode for in progress, **Remind
   missing** (one `batch`/`remindMissing` call), click student → profile (S13a's view if present, else
   `getStudentProfileAdmin` summary drawer).
5. Grading list: "Late" tag + due date for submissions from an assignment.
6. E2E `test/e2e/v5-hub-teacher.test.mjs` with gas mocks: create assignment, post + pin, tracker shows Late/Missing.

## S07b — Student side
**Model:** sonnet · **After:** B3, S06b · **Plan:** V5-10 "Student side"
**Owns:** `js/views/home/upnext.js`, `js/views/home/calendar.js`, `js/views/class.js` (new), `js/views/notifications.js`
(new), student rules in `css/hub.css` (under `.hub-student`; create the file if S07a's isn't merged yet)

1. Fill the home's `#home-upnext` slot from `getClassHub` (via profile `hub` field): due soonest first; chips Due
   tomorrow / Late / Missing / Optional practice / Opens Fri; one tap opens the test with the assignment's allowed modes.
2. 7-day calendar strip with due items.
3. Class page `?view=class&id=`: stream (pinned first), upcoming / past assignments, teacher name.
4. Bell in the student header with unread count; panel lists derived notifications; opening marks read
   (`markNotificationsRead`). Teacher reminders show as a banner on home.
5. Typing a code still works.
6. E2E `test/e2e/v5-hub-student.test.mjs`: assignment in Up next → opens without a code → submits after due (mock clock)
   → shows Late; bell count drops after opening.
