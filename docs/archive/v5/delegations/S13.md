## S13b — PWA + offline answering (optional)
**Model:** sonnet · **After:** S08c · **Plan:** V5-08 item 2
**Owns:** `sw.js` (new, root), `manifest.webmanifest` (new), `js/lib/sw-register.js` (new), `netlify.toml` (headers),
`js/lib/sync.js` (queue only)

Service worker: cache app shell + versioned assets (cache name includes `SITE_VERSION`; old caches deleted on
activate), network-first for `data/tests/*.json`, never cache Apps Script calls. Installable manifest using
`assets/brand/` icons. Answers already persist locally; queue `syncProgress` and submissions offline and send on
`online`. Update prompt when a new version is waiting. E2E: offline reload still opens a cached test.
