# S02 — Shared attempt model

## S02
**Model:** sonnet · **After:** S01a · **Plan:** V5-01 "Model" · **Contract:** V5 contracts → Attempt
**Owns:** `js/lib/attempt.js` (new), `js/views/runner.js`, `js/views/runner/*`, `js/views/mode-select.js`,
`js/views/game.js` (routing only), `css/runner.css`

1. Build `js/lib/attempt.js` exactly to the contract. It wraps the existing `progress:*` record (same key, same
   fields, only additions) so in-flight attempts from v4.1 still load. Pure module + storage; no DOM.
2. Move the runner's answer/flag/autosave/progress logic onto the attempt (behind `feature('v5Attempt')`; flag off =
   runner unchanged). The runner keeps its review screen and submit; submit uses `attempt.toSubmission()` and must
   produce byte-identical submissions to today for the same answers (unit test that).
3. **Mode switcher** in the runner bar: segmented control (menu on phones) listing `modesForTest(test)`; until S03
   lands, only **Study** is listed (read the list from `js/lib/modes/index.js` if it exists, else Study only).
   Switching calls `attempt.setMode(id)` and routes to `?code=…&mode=<id>`; Study keeps the current question.
   testids: `mode-switcher`, `mode-option-<id>`.
4. `mode-select.js`: with the flag on, shown only on a student's first visit to a test (remembers the choice),
   otherwise go straight to the runner in `attempt.lastMode`.
5. Tests: `test/unit/v5-attempt.test.mjs` (load v4.1 record, set/get/flags, answeredCount, results() with
   hidden-correctness tests → null, toSubmission parity); `test/e2e/v5-attempt.test.mjs` (answer 2, reload, still
   answered; switcher present with flag on via `?features=v5Attempt`).
