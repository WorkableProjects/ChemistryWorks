## S10
**Model:** sonnet · **After:** S06b, S09b · **Plan:** V5-06
**Owns:** `js/views/appearance.js` (new, shared component), `css/appearance.css` (new), `js/lib/theme.js`
(custom accent + contrast fix), `js/lib/contrast.js` (new or reuse the contrast helper the unit tests use),
`js/views/tools/settings.js` and `js/views/admin/settings.js` (mount only), `js/views/admin/palette.js` (new)

Behind `feature('appearance')`.
1. One component used in student Settings, the profile page slot `#profile-appearance` and admin Settings: theme
   3-way segmented control with mini previews; accent swatches with names, check on active, live preview card
   (button, link, pill, progress) in light and dark; **custom colour** picker that adjusts lightness until text-on-accent
   ≥4.5:1 and accent-on-page ≥3:1 in both themes (show the adjusted colour); text size S/M/L; density comfortable/
   compact; reduce motion; dyslexia-friendly font option (system font stack fallback, no new web font download unless
   one is already in `assets/`).
2. Saved locally and through `savePrefs()` (S06a) so it follows the student.
3. Admin command palette (Ctrl/⌘ K): jump to test, student, section; keyboard accessible; testid `command-palette`.
4. Consistent empty states: a small `emptyState({ icon, title, action })` in `js/ui.js`, used in student home, library,
   grading, bank.
5. Unit tests for the contrast fixer (random colours always pass both thresholds); e2e: pick custom colour → tokens
   applied and saved; palette opens with Ctrl+K and navigates.
