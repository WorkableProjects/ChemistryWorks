# S04 — Game modes II + removal

## S04a — Match-Up, Quiz Show, Race, Bingo
**Model:** sonnet · **After:** S03b · **Plan:** V5-01 "What happens to each game"
**Owns:** `js/lib/modes/{matchup,quizshow,race,bingo}.js`, `js/views/modes/{matchup,quizshow,race,bingo}.js`,
additions to `css/modes.css`

Use the S03 framework (read `mode-shell.js` + `modes/classic.js` first).
- **Match-Up:** pairs from the test: question ↔ correct answer for mcq / numeric / naming / formula items (key text via
  `correctAnswerText`), plus `matching` pairs. `available(test)` false when <3 pairs. A correct pair calls
  `attempt.set` with the value the runner would store.
- **Quiz Show:** board of tiles grouped by section (or topic, else by type), points by difficulty
  (`q.difficulty` or by points). Tile opens the widget.
- **Race:** track; right answer moves forward; ghost of the last run (localStorage per test).
- **Bingo:** 3×3 (≤12 questions) or 4×4 card of the test's questions; line = win; keeps going to full card.
- Unit tests for pair-building and board grouping; e2e smoke per mode in `test/e2e/v5-modes-3.test.mjs`.
