# S06 — Student home + profile (V5-02)

## S06a — Profile data layer + sync
**Model:** sonnet · **After:** B1, S02 · **Plan:** V5-02 · **Contract:** Student home + profile, Client API, Attempt
**Owns:** `js/lib/profile.js` (new), `js/lib/sync.js` (new), `js/lib/xp.js`, `js/lib/attempt.js` (sync hook only)

1. `profile.js`: local profile (from `cw:xp:<email>` + local results + progress records) merged with
   `getStudentProfile`; exposes `loadProfile()` (local first, then server; subscribe for update), `savePrefs()`.
   Demo sign-in / no backend → local only, `synced: false`.
2. `sync.js`: queues attempt + XP/badge deltas, calls `syncProgress` at most every 30 s, on mode switch and on
   `pagehide` (`sendBeacon` if the api allows; else best effort). Retries with backoff; never blocks the UI.
3. `xp.js`: XP/badges read from the profile when present; local stays the fallback. One-time migration of existing
   local XP into the first sync (server merge never lowers).
4. Cross-device "Continue": when the server has a newer attempt for a test than local, offer it (attempt merge rule
   from the contract).
5. Unit tests `test/unit/v5-profile.test.mjs` (merge local/server, throttle with fake timers, offline queue, migration).

## S06b — Student home and profile page
**Model:** sonnet · **After:** S06a · **Plan:** V5-02 "Student home layout"
**Owns:** `js/views/home/` (new), `js/views/profile.js` (new), `css/home.css` (new), `js/views/landing.js` (route
switch only), `js/app.js` (routes)

Behind `feature('studentHome')`; flag off = today's landing (with S01b fixes).
1. Home sections in order: header band (avatar, greeting from `js/lib/greetings.js`, level ring + XP, streak, class
   names, compact code field), **Up next** (placeholder slot `#home-upnext` that S07b fills; until then shows the
   most recent "Continue"), **In progress** (one deduped list, progress bar, last mode, Remove for 0-answered),
   **Results** (released scores + small SVG trend line, "Waiting for grading", View feedback), **Practice** (Mistake
   Review across tests, game bests, badges shelf). "Not synced" chip when offline.
2. Profile page `?view=profile`: stats (tests done, average, accuracy by topic from released results only), badges,
   history, an `#profile-appearance` slot (S10 fills), sign out.
3. Paint from local data instantly, update when the server answers (no spinner after first paint; skeletons OK).
4. Responsive (phone, Chromebook, desktop), tokens only, works in dark mode.
5. testids from the contract. E2E `test/e2e/v5-home.test.mjs` with mocked `getStudentProfile` (see
   `test/e2e/helpers.mjs` gas mocks): sections render, no duplicates, offline chip, profile page stats.
