# S03 — Game modes I

## S03a — Mode framework + Classic, Lightning, Survival
**Model:** sonnet · **After:** S02 · **Plan:** V5-01 · **Contract:** V5 contracts → Game mode definition
**Owns:** `js/lib/modes/` (new), `js/views/modes/` (new), `js/views/mode-shell.js` (new), `css/modes.css` (new),
routing in `js/views/game.js`

1. `js/lib/modes/index.js` registry + `modesForTest(test)` (honours `gameOptions` from `js/lib/games/options.js`;
   removed ids → all modes). Register `study` (routes to runner).
2. `js/views/mode-shell.js`: shared chrome for every mode — header with the S02 mode switcher, score/lives/timer slot,
   question host that renders **the runner widget** for the attempt's current question (`buildWidget` from
   `js/views/runner/widgets.js` / `typeUI(type).widget`), feedback card (reuse `js/views/games/feedback-card.js`
   styling), end summary (answered, score, **Review & submit** → runner review page, **Keep playing**).
   Teacher-graded types: "Saved — your teacher grades this". Hidden-correctness tests: "Saved", score by
   completion/speed (Decision 2).
3. Rebuild **Classic**, **Lightning Round**, **Survival** as modes (`js/lib/modes/<id>.js` rules + `js/views/modes/<id>.js`).
   Port scoring/pacing ideas from `js/lib/games/{classic,lightning,survival}.js`; drop their `*_TYPES` lists. Timers
   pause (or ×3) for long types: balance, graph, structure, lewis, multipart, datatable, and any `manual` type.
4. Every answer goes through `attempt.set` → shows as answered in Study. Leaderboard/best scores keep using
   `js/lib/leaderboard.js` keyed by test + mode id.
5. Behind `feature('v5Games')`; flag off = old games untouched (don't delete old code — S04b does).
6. Tests: `test/unit/v5-modes.test.mjs` (modesForTest with/without gameOptions and removed ids; a round contains
   exactly the test's question ids, no extras, none dropped); `test/e2e/v5-modes-1.test.mjs` (answer in Classic →
   answered in Study; every type in DEMOV4A/B/C renders in Classic without console errors).
