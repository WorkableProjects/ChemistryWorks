## S09a — Admin sidebar
**Model:** sonnet · **After:** S01a · **Plan:** V5-04
**Owns:** `css/admin-shell.css`, `js/views/admin/shell.js` (sidebar + section-change code only)

Width animates via `grid-template-columns` transition (~220 ms, `--ease-out`); labels fade + 4 px slide with short
stagger on expand, fade first on collapse; group headings → divider when collapsed; tooltips on hover/focus when
collapsed; active pill keeps sliding; phone drawer: backdrop fade, slide, swipe-to-close; section change cross-fade
(View Transitions where supported). E2E `test/e2e/v5-sidebar.test.mjs`: collapse state persists across reload; no
overlap at 768 / 1199 / 1200 px (bounding boxes); reduced motion → no transition.

## S09b — Motion pass

motion on and off.
