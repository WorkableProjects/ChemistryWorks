# S12 — Question types II (V5-07)

Same rules as the shared block at the top of `S11.md` — read it, then copy the pattern from the merged `ionbuilder`
(simple) or `ionicformula` (drag) type. Run up to 5 in parallel.

## S12a — `bohr` (Bohr / shell model)
**Model:** haiku · **After:** S11a, S11b
Concentric shells (teacher sets element or count); student taps to add/remove electrons per shell. Score: count per
shell exact; fraction = shells right / shells. Review draws the key.

## S12b — `oxidation` (Oxidation numbers)
**Model:** haiku · **After:** S11a, S11b
Formula or equation shown; a small number input above each atom (signed integer, accepts `+2`, `-1`, `0`). Teacher
enters the key per atom (auto-fill button using simple rules is optional). Score per atom.

## S12c — `solubility` (Solubility rules)
**Model:** haiku · **After:** S11a, S11b
Either mark each product/compound as (s) or (aq) with a toggle, or pick the precipitate from options. Teacher list of
compounds + key; optional auto-key from a rules table in the definition. Score per item.

## S12d — `heatcurve` (Heating / cooling curve)
**Model:** sonnet · **After:** S11a, S11b
SVG curve from teacher points (temperature vs heat/time); segments labelled by the student via dropdowns (phase(s),
"ΔH fus/vap", "q = mcΔT" vs "q = mΔH"). Teacher sets segments + key. Score per label. Accessible: labels reachable by
keyboard in segment order.

## S12e — `gaslaw` (Gas-law setup)
**Model:** sonnet · **After:** S11a, S11b
Student picks the law (Boyle, Charles, Gay-Lussac, combined, ideal, Avogadro), drags/types knowns into the formula
slots, solves. Unit handling via `js/lib/chemfuncs.js` / unit helpers if present. Score: law (0.25), setup (0.25),
numeric answer with tolerance + sig-fig option (0.5). Algorithmic variables supported.

## S12f — `molbuild` (Molecule builder)
**Model:** sonnet · **After:** S11a, S11b
Port the board from `js/lib/games/molbuilder.js` + `js/views/games/molbuilder.js` into a type (copy, don't import —
S04b deletes the game). Student places atoms and bonds; teacher sets the target molecule. Score: formula match
(0.5) + connectivity graph match ignoring layout (0.5). Valence check shown as a hint.

## S12z — DEMOV5 demo test
**Model:** haiku · **After:** S12a–S12f (and S11a–c)
Build `data/tests/DEMOV5.json` ("Demo — v5 question types") from every `test/fixtures/v5/*.json`, add it to the catalog
like DEMOV4A–C (and S08a's catalog file if merged), make `npm run validate:tests` pass, and add an e2e that opens
DEMOV5 and answers every question.
