## 2. Update the Google Apps Script (required for grading)

The grading feature needs the new backend code (version **1.1.0**).

1. Open your Google Sheet, then **Extensions → Apps Script**.
2. Select everything in `Code.gs`, delete it, and paste in the full contents of `apps-script/Code.gs` from this repository. Save.
3. **Deploy → Manage deployments**, click the pencil (**Edit**) on your existing deployment, set **Version: New version**, and click **Deploy**.
   - Don't choose "New deployment": that creates a different URL and you'd have to change `GAS_WEB_APP_URL` again.
   - Keep **Execute as: Me** and **Who has access: Anyone**.
4. Check it: open this link in a private/incognito window:
   `https://script.google.com/macros/s/AKfycbzPC-5Xv0b6XfVCKZ2xWQpK-WKgBQOHw2aGfneTcsPm-z3o9DvG42li3IVJ2RLcv0N7/exec?action=ping`
   It should show `{"result":"success","version":"1.1.0"}`. If it still says `1.0.0`, the new version wasn't deployed (repeat step 3).

Your existing **Submissions** tab gets six new columns automatically on the next submission: Status, Final Score, Final Percentage (%), Grades (JSON), Graded At, Teacher Note. Old rows are kept.

## 3. Make sure the admin key is set (required for grading and publishing)

1. In Apps Script: **Project Settings** (gear icon) → **Script properties**. There should be a property named `ADMIN_KEY` with a long passphrase. If it's missing, add it.
2. On the site, open the admin panel (**Teacher / admin**, bottom-right of the home screen), go to **Settings**, paste the same passphrase into **Admin key**, and click **Save key**. Then click **Test connection**; it should say `Connected · v1.1.0`.
   - The key is remembered only until the browser tab is closed, so you'll paste it again in each new session.

Don't put the `ADMIN_KEY` value in `config.js` or anywhere in the repository.

## What's new (for reference)

- **One-link tests:** every published or bundled test has a **Copy student link** button in the Library, and after **Publish to Sheet** the builder shows the link with a Copy button. Students open the link, sign in with Google, and the test starts. Post it in Google Classroom or email it.
- **Teacher grading:** the new **Short answer** question type is graded by you in the **Grading** tab. You can also override auto-graded points, add a private note, and **Export grades** to a CSV for Aeries or Google Classroom.
- **Hide scores:** the per-test **Show score to students** switch. When it's off, students only see "Submission received".
- **Home screen:** a single login panel.
- **AI test guide:** [`docs/guide.md`](guide.md). Give it to an AI to write tests in the right JSON format, then import them via Builder → Import JSON.

## Security limitation (for awareness)

The test file, including its answer key, is loaded into the student's browser. A tech-savvy student could find the answers using the browser's developer tools, and hiding the score doesn't change that. For high-stakes tests, rely on `short` (teacher-graded) questions, which have no answer key in the file except the optional `sampleAnswer` (leave that empty for those tests).
