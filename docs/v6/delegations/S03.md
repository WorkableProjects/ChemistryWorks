# S03 — Client security (plan V6-02 #4, #9, #12)

## S03 — Submit with a readable reply, Google-only admin sign-in, feedback token
**Model:** sonnet · **After:** B1, S02a · **Contract:** V6 → Submit, Admin access
**Owns:** `js/lib/submit.js`, `js/app.js` (admin gate only), `js/lib/admin-session.js`, `js/config.js`
(`ADMIN_ACCESS_CODE` removal), `js/lib/api.js` (`fetchFeedback`), `js/views/feedback.js`,
`js/views/admin/settings.js` (key field copy), related unit and e2e tests

1. **Submit (#9):**
   - Post `text/plain` **without** `no-cors` and read the JSON reply.
   - `success` → done.
   - `error` with a final code (`closed`, `not_on_roster`, `single_submission`, `submission_too_large`) → show it, don't queue.
   - Network error, timeout (15 s), `server_error` or `busy` → keep in the outbox with the same `submission_id`, and show
     "Not sent yet — we'll retry" with a Retry button.
   - Unit tests for each branch. Update the resilience e2e tests.
2. **Admin sign-in (#12, Decision 3):**
   - Delete `ADMIN_ACCESS_CODE`, `accessCodeGate()` and the "Use access code instead" button.
   - Admin = Google sign-in + `whoami` on the `Admins` sheet.
   - When Google **isn't configured** (no `GOOGLE_CLIENT_ID`: local dev and e2e), a demo admin sign-in is allowed. It
     must be impossible when a client ID is set. Unit test for that.
   - `ADMIN_KEY`: admin → Settings keeps a "Sheet key" field, worded as the backend credential (e.g. for set-up before
     the Admins sheet has an owner). It is never required to open the admin panel.
   - Update `README.md`'s "use the demo code `chemadmin`" line only if it is still there; otherwise leave docs to S13b.
3. **Feedback (#4):** `fetchFeedback` sends the student's ID token. The feedback view asks the student to sign in when
   there's no token, and handles `not_authorized`.
4. **E2E:**
   - The admin panel opens without any code locally.
   - With a client ID configured (mocked), there is no code field anywhere.
   - A failed submission stays in the outbox and Retry sends the same ID.
