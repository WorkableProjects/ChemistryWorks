1. **`## V6 contracts`** in `docs/ARCHITECTURE.md`, with these subsections:
   - **TypeDef (all 42 types):**
     - The registry contract, extended so the 20 built-in types fit: `normalize`, `validate`, `grade`, `format`, `blank`, `isAnswered`, `toPdf`, plus UI `render(widgetCtx)` and editor `edit(editorCtx)`.
     - UI and editor modules are loaded lazily (`loadTypeUI(type)`, `loadTypeEditor(type)`). Definitions stay synchronous.
     - The answer-fixture shape the conformance test uses: `test/fixtures/types/<type>.json` = `{ question, correct, wrong, partial? }`.
      - `correct`, `wrong` and `partial` are answer values the widget would produce.
      - The existing `test/fixtures/v5/<type>.json` files are question arrays only. S02c moves them into this shape.
   - **Kill switches:** `CONFIG.KILL_SWITCHES = { classHub, gameModes, studentSync }`, all default `false`. `killed(name)` replaces `feature(name)`.
   - **CSS loading:** `ensureCss(name)` in `js/lib/css-loader.js`; which views own which stylesheets; `?v=SITE_VERSION` on every URL.
   - **Backend errors:** reply shape `{ result: 'error', error: '<code>', ref: '<shortId>' }`. List the codes.
   - **Submit:** a `text/plain` POST with a readable reply; outbox rules (what is retried, what is final).
   - **Identity:** stored email comes from the token; `ALLOW_UNVERIFIED_EMAIL` rows are marked `unverified`.
   - **Admin access:** Google ID token + `Admins` sheet; `ADMIN_KEY` only as the Sheet credential; demo admin only when Google isn't configured.
   - **Tags (V6-09 B):**
     - The `Tags` sheet columns.
     - The local store key `cw:tags:<email>` and its record shape (`{ id, name, color, description, onSheet, updatedAt }`).
     - The ID format `tg_` + 6 base-36 characters, made in the browser.
     - The question field `tags: string[]` (at most 10).
     - The `publishTest` `tagDefs` field.
     - Actions `listTags`, `saveTag` (edit only), `deleteTag`, `mergeTags`, with request and reply shapes.
     - `tagIndex` in test payloads.
   - **Google Classroom (V6-09 A):**
     - Scopes.
     - The `ClassroomSync` sheet columns.
     - New columns `Classes.classroomCourseId` and `Assignments.classroomCourseWorkId`.
     - Actions `listClassroomCourses`, `linkClassroomCourse`, `importClassroomRoster`, `previewGradeSync`, `syncGrades` (cursor), and `saveAssignment.postToClassroom`, with request and reply shapes.
     - The grade rules: draft vs assigned grade, the overwrite guard.
   - **Backend housekeeping:** `setupTriggers()`, retention settings keys, the `diag` reply shape.
