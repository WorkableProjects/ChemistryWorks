## S02d — E2E coverage for v5 + no fixed sleeps
**Model:** sonnet · **After:** S02a · **Plan:** V6-01 "New e2e tests", "Remove fixed sleeps"
**Owns:** `test/e2e/{home,class-hub,modes,perf}.test.mjs` (new), `test/e2e/helpers.mjs` (add a `gasDelayMs` option and
stateful mock-backend helpers), and sleep removal in every e2e file

1. **`home.test.mjs`:** student home sections render from the mock profile; "Continue" opens the last attempt; no duplicate tests; the offline "Not synced" chip.
2. **`class-hub.test.mjs`:** teacher assigns (mock backend keeps state) → the student sees it in Up next → opens it with no code → submits after the due time → the tracker shows Late. Stream post → the student sees it, and the bell shows a notification.
3. **`modes.test.mjs`:** for each of the 12 modes, play one auto-graded and one teacher-graded question. Switching mode keeps answers, and an answer given in Classic shows as answered in Study.
4. **`perf.test.mjs`** (the old v5 S08d brief), with every mock gas reply delayed 1500 ms:
   - Draft delete removes the row in < 100 ms with no gas request.
   - Published delete removes the row in < 300 ms.
   - The warm Library opens in < 300 ms.
   - Save grade → next student in < 300 ms with one request.
   - Switching sidebar sections and back makes no request.
   
   Use `performance.now()` deltas.
5. **Remove fixed sleeps:** replace every `waitForTimeout` and `setTimeout` sleep in `test/e2e/` with a wait on a selector, a response or `expect.poll`-style polling. Grep must find none left.
