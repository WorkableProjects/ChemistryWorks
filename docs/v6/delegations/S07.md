## S07 — Escape teacher content; add CSP and SRI
**Model:** sonnet · **After:** S03, S06b
**Owns:** `js/ui.js` (`html:` prop), every `html:` call site, `js/lib/qtypes/reaction.js`, `econfig`, `bohr` and other
string-to-HTML helpers, `index.html` (`<meta http-equiv="Content-Security-Policy">`, `integrity` attributes),
`test/unit/xss.test.mjs` (new), `test/e2e/csp.test.mjs` (new)

1. **List every `html:` use** (about 21) and every `innerHTML` / `insertAdjacentHTML`. For each, record its source:
   constant, escaped, or teacher/student text.
2. **Escape anything that comes from text:**
   - Fix the helpers (`joinHTML`, `configToHTML`, the `bohr` diagram, chart labels) to escape their inputs.
   - Where possible, replace `html:` with `h()` and text nodes.
   - KaTeX output stays as HTML: KaTeX escapes its input, and `trust` must be off. Check.
3. **`xss.test.mjs`:** feed `<img src=x onerror=alert(1)>`, `"><svg onload=…>` and `javascript:` links through every
   helper and every type's `format`/`toPdf`, and assert that no element or event handler is created.
4. **CSP `<meta>`:**
   - `default-src 'self'`
   - `script-src 'self' https://cdnjs.cloudflare.com https://accounts.google.com`
   - `connect-src 'self' https://script.google.com https://script.googleusercontent.com https://oauth2.googleapis.com https://raw.githubusercontent.com`
   - `style-src 'self' 'unsafe-inline' https://fonts.googleapis.com https://cdnjs.cloudflare.com https://accounts.google.com`
   - `font-src https://fonts.gstatic.com https://cdnjs.cloudflare.com`
   - `img-src 'self' data: https:`
   - `frame-src https://accounts.google.com`
   
   Remove `'unsafe-inline'` from `script-src` if there are inline scripts (move them to files).
   `csp.test.mjs` loads every main view and fails on any CSP violation (`securitypolicyviolation` listener).
5. **SRI:** add `integrity` + `crossorigin` on the KaTeX CDN links (pinned 0.16.11). Google Fonts CSS can't use SRI;
   leave it and note why in a comment.
