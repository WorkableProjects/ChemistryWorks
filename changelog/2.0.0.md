# 2.0.0 — 2026-11-02

## Added
- Submission counts per test in the library.
- Split-screen reference pane: periodic table (CST reference sheet values), per-test constants, notes and images.
- Partial credit: Full / Half / Zero buttons or any score; changes to auto-graded scores are saved as overrides.
- Sections with instructions and automatic point totals.
- Orbital diagram question type (teacher graded).
- Lewis structures can require brackets, an overall charge and formal charges.
- Teacher comments per question, released to students with the grade.
- PDF export of a student's reviewed submission.
- Students can see their past submissions and released feedback.

## Changed
- Lab-notebook look: warm paper surfaces, ink-blue text, monospace formulas.
