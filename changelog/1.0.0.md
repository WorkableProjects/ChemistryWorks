# 1.0.0 — 2026-10-30

First release.

## Added
- Google sign-in for students; enter a test code or open `/test?code=CODE`.
- Student test runner with auto-save, keyboard navigation and live formula rendering (KaTeX + mhchem).
- Question types: multiple choice, Lewis dot diagrams, Lewis structures (bonding), fill-in-the-blank, ordering, short answer and open response.
- Instant client-side scoring and a results screen.
- Submissions saved to Google Sheets through Apps Script, with Netlify Forms as a backup.
- Teacher panel (`?admin=true`): visual and JSON test builder, preview, publish, Grading tab and gradebook CSV export.
- Light / dark mode.

## Security
- Spreadsheet formula injection blocked in Sheet rows and CSV exports.
