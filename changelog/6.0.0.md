# 6.0.0 — 2026-11-13

Backend upgrade required: update `Code.gs`, then run `setup` once (see DEPLOYMENT.md, "Upgrading to v6").

## Added
- **Question tags.** Put tags like "Ions" or "Unit 3" on questions in the builder. A tag stays on your device until a published test uses it; then every teacher can use it.
- **Admin → Tags** to create, rename, recolour, merge and delete tags, with how many questions and tests use each one.
- Filter the builder's question list, the library and grading by tag. Grading shows the average score for each tag.
- Students see a **By topic** summary on released results, and their profile shows accuracy by tag.
- Flashcards and Mistake review can practise one tag at a time.
- **Google Classroom grade sync.** Link a class to a Classroom course, import its roster, post an assignment to Classroom, then preview and sync grades. Unreleased scores go as draft grades only you can see.
- The app works offline after the first visit and can be installed. When a new version is ready you see "Update available".
- Admin → Settings → Platform: sheet sizes and speed, how long old rows are kept, and a checklist for this deployment.

## Changed
- Admins sign in with Google only. The admin access code is gone.
- A submission is only counted as sent once the Google Sheet confirms it. Otherwise it waits on the device and shows "Not sent yet — we'll retry".
- Student identity on submissions and feedback now comes from Google sign-in, not from what the browser says.
- Tests limited to a class roster are only served to signed-in students on that roster.
- The daily clean-up keeps the Sheet small: live progress, the log, error reports and old class posts are trimmed.
- Screen readers hear the name of each new page instead of the whole page.

## Fixed
- A busy Sheet no longer makes student progress saves wait 10 seconds.
- Game scores, streaks and badges can no longer be inflated from the browser.
- Old Netlify settings and the hidden backup form are removed.
