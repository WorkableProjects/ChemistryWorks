# 6.0.0 — 2026-11-19

Backend upgrade required: see DEPLOYMENT.md.

## Added
- **Google Classroom grade sync.** Link a class to a Classroom course, import the roster, post tests as Classroom assignments and send grades back. Grades that aren't released yet go as draft grades.
- **Question tags.** Tag questions by topic in the builder. Grading, the tracker, results, feedback and the student profile show scores by topic, and study modes can filter by topic.
- **Install and offline use.** ChemistryWorks can be installed like an app. Answers are saved on the device when you're offline and sent when you're back.
- Full-width question view for students on large screens.

## Changed
- Admin sign-in is Google only. The admin access code is gone.
- Submissions retry until they arrive, and you see when one is still waiting.
- Pages load faster: each screen and question type loads only what it needs.
- Keyboard alternatives for drag-and-drop questions, and screen readers announce each new page.
- Feedback is only shown to the signed-in student it belongs to.

## Fixed
- The banner for answers waiting to send was missing from the student home.
- Students could read another student's Class Hub by changing a request.
- Admin grading lost the late and due-date details on some rows.
