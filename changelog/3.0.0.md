# 3.0.0 — 2026-11-03

## Added
- Verified student identity and student status checks.
- Released feedback opens from the test link.
- Single-submission tests (repeat attempts blocked, "Take again" hidden).
- Required questions: per question, or "All questions required" for the whole test.
- New question types: equation balancing, electron configuration, periodic table pick, significant figures, categorize, hotspot and graph.
- Game picker and more games; new question types work in games.
- Motion system: view transitions, landing and results animations, Reduce motion switch.
- New ChemWorks logos and animated flask loader.

## Changed
- Accessibility pass across student and teacher views.
- Views are lazy-loaded and KaTeX loads only when a page has math.
