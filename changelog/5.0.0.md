# 5.0.0 — 2026-11-11

Backend upgrade required: see DEPLOYMENT.md

## Added
- **Class Hub.** Teachers can set assignments with open and due dates, post to a class stream, see who has not handed in work, and send reminders. Students see what is coming up, a calendar strip, class pages and notifications.
- **Student home and profile.** Students get a home page with their progress, and a profile that follows them across devices.
- **More ways to practise.** New modes: Classic, Lightning, Survival, Flashcards, Mistake review, Tower, Boss battle, Match-Up, Quiz show, Race and Bingo. You can switch mode from the bar while working.
- **New question types.** Ionic formulas, atom and ion builder, average atomic mass, Bohr model, oxidation numbers, solubility rules, heating curves, gas laws and molecule builder.
- **Appearance panel.** Pick an accent colour and text size. Colours are adjusted so text stays readable.
- **Teacher student view.** Teachers can see a class page as a student sees it.
- **Command palette** for jumping around the admin panel.
- **Saved attempts.** A student's attempt is saved to their account, so they can carry on from another device.

## Changed
- Pages load faster: test lists, results and class rosters are read in smaller, cached requests.
- A cleaner, calmer look across the site, with softer motion.
- The landing lists are merged into one list without duplicates, and empty practice cards are hidden.
- **Removed:** Insights, Mastery, and the six stand-alone games (Unit Dash, Reaction Lab, Molecule Builder, Periodic Puzzle, Daily Element and the separate Boss Battle game).

## Fixed
- Answered and total question counts now show correctly on the landing list.
